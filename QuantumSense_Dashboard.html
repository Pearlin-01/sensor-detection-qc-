⚛️ Quantum Circuit Architecture (ZZFeatureMap)

Non-linear Hilbert space embedding via 4-qubit second-order Pauli-Z entanglement

The ZZFeatureMap encodes classical sensor features $\mathbf{x} \in \mathbb{R}^4$ into quantum state vectors $|\Phi(\mathbf{x})\rangle$ in a $2^4 = 16$-dimensional complex Hilbert space using the unitary operator:
$U_{\Phi(\mathbf{x})} = \exp\left(i \sum_j \phi_j(\mathbf{x}) Z_j + i \sum_{j < k} \phi_{jk}(\mathbf{x}) Z_j Z_k\right)$

ℹ️ Project Documentation & Architecture

B.Tech Computer Science Engineering Project

QuantumSense is a quantum-enhanced machine learning framework designed for multi-sensor anomaly detection and industrial IoT fault diagnosis. By evaluating classical support vector classifiers alongside quantum fidelity kernels (QSVC), the system establishes rigorous benchmarks on high-dimensional non-linear sensor telemetry.


Key Capabilities:

  • Multi-modal statistical window feature engineering (mean, std, min, max, polyfit slope across 3 physical channels).
  • Leakage-free stratified dataset partitioning and $[0, \pi]$ angle normalization for quantum circuits.
  • High-fidelity Statevector kernel matrix calculation via Qiskit Machine Learning.
  • Full RESTful Flask backend with zero-latency telemetry streaming.
