About QuantumSense

Academic foundation, architecture, and technology stack for quantum-enhanced sensor fault detection.

Registration ID: URK24CS1111

Project Abstract

B.Tech CSE Project

QuantumSense is an end-to-end sensor fault detection and telemetry monitoring system that investigates the diagnostic efficacy of Quantum Machine Learning (QML) relative to classical Support Vector Machines (SVM). Designed for Industrial Internet of Things (IIoT) applications, the platform simulates and analyzes multi-modal signals from temperature, pressure, and vibration sensors, classifying anomalous behavior across five distinct fault categories.

By integrating a Fidelity Quantum Kernel based on parameterized ZZFeatureMap circuits simulated via Qiskit, QuantumSense empirically benchmarks quantum Hilbert-space state embeddings against classical radial basis function (RBF) kernels on held-out test telemetry.

Project Objectives

  • Synthetic Multi-Sensor Simulation: Generate reproducible, physics-grounded telemetry for Temperature, Pressure, and Vibration sensors across five distinct operational modes.
  • Custom Dataset Ingestion: Support custom industrial CSV dataset uploads with automated column role detection, sliding-window time-series feature engineering, and robust cleaning.
  • Feature Engineering Pipeline: Extract fifteen statistical sliding-window features (mean, std dev, minimum, maximum, trend slope) without data leakage.
  • Classical Machine Learning Baseline: Implement a robust, multi-class Support Vector Classifier (SVC) using scikit-learn with an RBF kernel.
  • Quantum Machine Learning Implementation: Formulate a 4-qubit Quantum Support Vector Classifier (QSVC) utilizing Qiskit Machine Learning and local statevector fidelity simulation.
  • Empirical Rigorous Benchmarking: Benchmark models side-by-side using Accuracy, Macro and Weighted Precision, Recall, F1-Score, and Wall-Clock Latency without fabricating quantum advantage.
  • Actionable Maintenance Guidance: Provide engineering inspection checklists and severity assessments for detected fault conditions.
